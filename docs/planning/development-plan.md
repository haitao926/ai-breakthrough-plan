# 学生科创项目平台 - 开发内容梳理

## 1. 开发阶段（对齐 PLATFORM_IMPROVEMENT_PLAN）
### 阶段 1：数据基础 + 生命周期闭环
- 引入数据库与核心模型
- 开题提交 + 立项审核
- 里程碑1/2/3 提交 + 反馈记录
- 中期评审节点
- 结题提交 + 归档状态

### 阶段 2：核心流程整合
- 教师端评审与评价闭环
- 项目时间线与状态追踪

### 阶段 3：体验优化与系统集成
- 前端 SPA 化（可渐进）
- Gitea 基础集成（提交记录/预览）

### 阶段 4：社区生态建设
- 展示墙与推荐机制
- 讨论区与公告系统

## 2. MVP 功能清单（模块化）
- 立项：开题提交 + 审核 + 状态流转。
- 过程：里程碑1/2/3 + 中期评审 + 反馈记录。
- 结题：结题报告 + 成果归档。
- 老师面板：列表、筛选、下载、导出。

## 3. 优先级拆分（MVP → 扩展）
### P0（必须）
- 立项 → 里程碑 → 结题全流程可跑通
- 状态可追踪、附件可下载

### P1（重要）
- 统计与导出
- 展示墙（基础版）

### P2（增强）
- 评分体系与多角色
- 资源/经费/竞赛管理

## 4. 关键验收点
- 项目从立项到结题全流程闭环完成。
- 老师可查看各阶段提交并下载附件。
- 项目状态、里程碑状态可追踪。

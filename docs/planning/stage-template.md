# 阶段模板与提交字段（融合版）

本模板用于统一“开题-里程碑-中期-结题-展示”全生命周期的提交内容与结构。

## 1. 提交类型与对应阶段
- `proposal`：开题（闸门1）
- `milestone_1`：里程碑1（功能一：需求调研与可行性）
- `milestone_2`：里程碑2（功能二：方案设计与原型）
- `midterm`：中期评审（闸门2）
- `milestone_3`：里程碑3（项目集成：MVP 验证）
- `final`：结题评审（闸门3）
- `showcase`：展示/归档（可选）

## 2. 阶段字段建议
### 开题（proposal）
- 问题与背景
- 目标
- 范围（做/不做）
- 技术路线
- 计划（阶段安排）
- 成员列表
- 附件（可选）

### 里程碑1（milestone_1）
- 需求调研结论
- 可行性分析
- 风险清单
- 功能一范围说明
- 附件（调研报告/竞品分析）

### 里程碑2（milestone_2）
- 方案设计说明
- 原型或架构图
- 关键路径与技术难点
- 附件（原型图/架构图）

### 中期评审（midterm）
- 进度对比（计划 vs 现状）
- 演示链接
- 遇到的问题与调整
- 附件（演示视频/阶段报告）

### 里程碑3（milestone_3）
- 项目集成说明（联调/测试）
- MVP 验证与反馈
- 核心功能完成情况
- 附件（测试报告/反馈记录）

### 结题评审（final）
- 成果包清单（源码/文档/演示）
- 演示说明
- 技术总结
- 反思与展望
- 附件（成果包/演示材料）

### 展示/归档（showcase）
- 海报/视频/可复用资源说明
- 附件（海报/视频/宣传图）

## 3. 状态与流转（建议）
- `proposal` 提交后进入“审核中（reviewing）”
- `midterm` 提交后进入“中期评审（midterm_review）”
- `final` 提交后进入“结题待审（final_review）”
- 老师确认后进入“已归档（archived）”

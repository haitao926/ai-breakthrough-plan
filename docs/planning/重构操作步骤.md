# 目录重构复制操作步骤

> 注意：此文档记录旧的“复制阶段”流程，当前迁移已完成，仅作历史参考。

本文档记录“第一阶段：复制”操作的执行步骤，遵循“先复制、后清理”的安全策略。

## 目标与原则

- 目标：将课程内容、服务、学生数据、脚本、平台文档和历史归档复制到新结构中。
- 原则：只复制不删除；保留隐藏文件与文件属性；确保目标目录存在。

## 目录映射

| 源目录/文件 | 目标目录 |
| --- | --- |
| `course-files/` | `📁 2_Course_Content/` |
| `gitea/` | `📁 3_Services/` |
| `uploads/` | `📁 4_Student_Data/` |
| 根目录脚本 `*.sh *.bat *.ps1` | `📜 scripts/` |
| `docs/innovation-platform/` | `📁 1_Source_Code/🚀 platform_next/docs/` |
| `archive/`、`backup/` | `🗃️ z_Archive/` |

## 执行步骤（在项目根目录执行）

### 1) 准备目标目录

```bash
mkdir -p "📁 2_Course_Content" "📁 3_Services" "📁 4_Student_Data" "📜 scripts" \
  "📁 1_Source_Code/🚀 platform_next/docs" "🗃️ z_Archive"
```

### 2) 复制课程内容、服务和学生数据

```bash
cp -a course-files/. "📁 2_Course_Content/"
cp -a gitea/. "📁 3_Services/"
cp -a uploads/. "📁 4_Student_Data/"
```

### 3) 复制根目录脚本到 `📜 scripts`

```bash
find . -maxdepth 1 -type f \( -name "*.sh" -o -name "*.bat" -o -name "*.ps1" \) \
  -exec cp -a {} "📜 scripts/" \;
```

### 4) 复制平台文档到新平台目录

```bash
cp -a docs/innovation-platform/. "📁 1_Source_Code/🚀 platform_next/docs/"
```

### 5) 复制历史归档到 `🗃️ z_Archive`

```bash
cp -a archive "🗃️ z_Archive/"
cp -a backup "🗃️ z_Archive/"
```

## 验证建议

```bash
du -sh course-files "📁 2_Course_Content"
du -sh gitea "📁 3_Services"
du -sh uploads "📁 4_Student_Data"
```

如需更严格对比，可使用：

```bash
diff -qr course-files "📁 2_Course_Content"
diff -qr gitea "📁 3_Services"
diff -qr uploads "📁 4_Student_Data"
```

## 后续清理（可选）

确认新结构可用后，再决定是否将旧目录移动到归档或删除。本阶段不执行删除操作。

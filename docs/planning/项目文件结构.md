## 🎯 关键文件说明

### 核心运行文件
1. **server-complete.js** - 主服务器（推荐使用）
2. **index-new.html** - 前端主页面
3. **package.json** - 依赖配置

### 快速启动
1. 双击 `start.bat` 启动服务器
2. 双击 `打开课程平台.bat` 访问平台

### 访问地址
- 本地：http://localhost:8080
- 局域网：http://10.20.203.245:8080

## ⚠️ 注意事项

1. **server.js vs server-complete.js**
   - server.js：基础版本
   - server-complete.js：完整版本，包含错误处理和更多功能（推荐）

2. **index.html vs index-new.html**
   - index.html：原始版本，纯展示
   - index-new.html：增强版本，包含下载功能（服务器默认指向此文件）

3. **course-files目录**
   - 启动时会自动创建
   - 需要手动添加课程资料

4. **node_modules目录**
   - 包含所有依赖包
   - 不要手动修改
   - 如需重新安装：删除后运行 `npm install`

## 📝 使用建议

1. **首次使用**
   - 运行 `npm install` 安装依赖
   - 使用 `start.bat` 启动服务器

2. **添加资料**
   - 将文件放入 `course-files/` 对应目录
   - 刷新浏览器查看新文件

3. **故障排除**
   - 检查8080端口是否被占用
   - 查看服务器控制台错误信息
   - 确认Node.js已正确安装

Monorepo Platform

把科创课程与项目推进放进同一套系统

SASU AI Lab 是一个面向学生科创实践的统一平台，把课程内容、账号登录、项目管理、 阶段提交、资料下载、成果展示与代码托管串联到一起，让“从选题到展示”形成一条连续的工作流。

Project Value

不是单个网页，而是一条完整的科创推进链路

当前项目的重点不只是“展示页面”，而是把学生做项目时会分散在不同地方的动作收拢起来： 学习资料、任务分解、阶段成果、教师反馈、代码仓库和最终展示都能在同一个体系里被追踪和连接。

课程到项目

从选题、预研、文献整理、创新点梳理到开题提交，前置环节被设计成可执行的工具链。

过程可记录

项目日志、里程碑、提交记录和教师审核形成过程证据，而不只是最终一次性交作业。

协作可延展

通过 Gitea 与文件存储，把代码、文档、压缩包与成果展示统一到同一套运行环境中。

Architecture

以 Monorepo 为中心组织应用、内容、服务与数据

仓库结构已经围绕“平台化”重组：前端与后端分离开发、运行时数据单独落盘、脚本专门负责启动和运维， 文档与课程内容也不再散落在各处，后续扩展会更稳定。

Apps
`apps/web-vue` + `apps/api` Vue 前端负责界面与交互，Fastify 后端负责认证、数据接口、文件下载与静态资源托管。
Content
`content/` 课程与材料 集中管理课程结构、素材与教学内容，方便长期维护与课程迭代。
Services
`services/gitea` 提供本地代码托管能力，适合学生团队项目协作和阶段性代码留档。
Storage
`storage/db` + `storage/uploads` + `storage/logs` SQLite 保存业务数据，上传目录保存附件，日志目录保留运行与审计信息。

Workflow

围绕学生真实项目推进节奏设计使用路径

页面、接口和工具并不是孤立的。它们共同服务于一个更实际的目标： 让学生做项目时知道下一步做什么，老师查看过程时能看到依据，展示成果时能直接拿出证据链。

01
登录进入平台

学生或老师通过统一入口登录，进入工作台、教师端或任务工具区。

02
完成预研与规划

使用开题、文献、创新点、架构和看板工具，把想法转成可执行计划。

03
记录开发与提交

上传阶段材料、填写日志、关联代码仓库与提交记录，留下清晰的过程凭据。

04
教师审核与展示

教师端查看项目状态与成果，最终通过展示页、下载中心和成果材料完成输出。

当前对外入口
Platform

Web 平台本地运行在 `http://localhost:8090`，由后端统一对外提供访问入口。

Gitea

代码仓库服务运行在 `http://localhost:3000`，用于项目协作和代码成果留档。

Storage

业务数据保存在 SQLite，附件、日志与运行记录统一进入 `storage/` 目录。

技术关键词

前端使用 Vue 3 + Vite，后端使用 Fastify，数据层以 SQLite 为主，代码托管使用 Gitea。 整体以 Monorepo 组织内容、应用、脚本与文档，适合课程项目长期迭代，也方便后续继续加入评审、 展示、AI 辅助与更多教学工具。

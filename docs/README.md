# SASU AI Lab - 创新平台文档库

欢迎来到 SASU AI Lab 的官方平台开发文档库。

本目录旨在为平台的开发者和维护者提供一个清晰、准确、统一的信息来源。所有关于平台开发的关键文档都将在这里进行集中管理，并根据其内容和目的进行分类。

## 文档结构

- 📜 [**1. 产品需求与任务计划 (Product Requirements & Task Plan)**](./planning/1_product_requirements.md)
  - *本篇文档是所有开发的起点，定义了平台需要“做什么”。它详细描述了平台的远景目标、核心功能、用户故事、业务流程，并包含了从 MVP 到完整生态的详细开发路线图和任务优先级。*

- 🏗️ [**2. 技术架构 (Technical Architecture)**](./architecture/2_architecture.md)
  - *本篇文档是开发的工程蓝图，定义了平台“怎么建”。它包含了项目的技术选型、前后端架构、API 接口规范、数据模型设计、部署策略以及已知的架构改进点。*

- 🎨 [**3. 设计原则 (Design Principles)**](./architecture/3_design_principles.md)
  - *本篇文档是产品的灵魂，定义了平台“为什么这样设计”。它阐述了平台在用户体验（UX）和用户界面（UI）方面的核心设计哲学，包括用户驱动的开发流程、MVP 的定义方法以及推荐使用的设计工具与资源。*

## 使用指南

- **开始新功能开发前**: 请务必阅读 [**产品需求与任务计划**](./planning/1_product_requirements.md)，以理解功能的业务背景和验收标准。
- **进行技术选型或重构时**: 请参考 [**技术架构**](./architecture/2_architecture.md)，以确保与现有体系保持一致。
- **进行页面或流程设计时**: 请遵循 [**设计原则**](./architecture/3_design_principles.md) 中阐述的理念。

通过这套文档，我们希望能确保团队成员对平台有统一的认知，减少沟通成本，提高开发效率和质量。

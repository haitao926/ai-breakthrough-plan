# 项目1：体感互动游戏

## 🎮 超级任务
**成为体感游戏魔法师 - 用身体控制游戏**

AI识别你的动作 → 控制游戏角色 → 科技节展示作品

---

## 项目定位

### 最终成果
制作一个**身体控制的互动游戏**，体验AI + 游戏开发的乐趣

### 项目亮点
- ✅ **酷炫体验** - 不用手柄，用身体控制游戏
- ✅ **AI技术** - 体验AI如何识别人体动作
- ✅ **快速开发** - AI辅助编程，效率倍增
- ✅ **成就感强** - 短时间内做出可玩的游戏

---

## 游戏方案（2选1）

### 🦖 方案A：体感小恐龙
**玩法**：
- 玩家跳跃 → 小恐龙跳跃躲避障碍
- 玩家蹲下 → 小恐龙钻过飞鸟
- 简单有趣，容易实现

### 🍉 方案B：体感切水果
**玩法**：
- 玩家挥手 → 切割飞出的水果
- 动作幅度大，运动感强
- 适合展示和互动

---

## 核心技术

### 技术栈
- **姿态识别**：MediaPipe（Google开源AI模型）
- **游戏引擎**：Phaser.js（轻量级HTML5游戏框架）
- **AI编程**：ChatGPT辅助代码生成

### 实现流程
```
摄像头捕捉 → AI识别人体关键点 → 动作检测 → 游戏控制
```

## 4节课详细安排（45分钟/节）

### 第1节：🤖 AI初体验 - 姿态识别的魔法

#### 角色定位
**动作探索师** - 发现AI如何"看懂"人类动作

#### 学生视角
"AI真的能识别我的跳跃和挥手，太神奇了！"

#### 任务流程

**导入热身 (5分钟)**
- 观看体感游戏视频（Kinect、VR游戏）
- 激发兴趣："今天让AI看懂你的动作"

**核心学习 (20分钟)**
1. MediaPipe体验（10分钟）
   - 打开MediaPipe网页demo
   - 观察AI识别人体33个关键点
   - 体验实时骨架追踪

2. 动作测试（10分钟）
   - 测试3个基础动作：跳跃、蹲下、挥手
   - 观察关键点数据变化
   - 记录哪些动作识别最准确

**动手实践 (15分钟)**
1. 游戏方向选择（5分钟）
   - 小组投票：体感小恐龙 vs 切水果
   - 确定最终游戏方向

2. AI辅助设计（10分钟）
   - 使用ChatGPT生成简单游戏规则：
     ```
     "设计一个体感控制的小游戏，
     玩家用跳跃和蹲下控制角色，
     规则简单易懂"
     ```
   - 确定动作映射方案

**总结分享 (5分钟)**
- 展示各组的游戏想法
- 分享动作测试发现

**交付物**：
- ✅ MediaPipe姿态识别成功体验
- ✅ 3个动作的测试记录
- ✅ 游戏方向选择和基础规则

## 项目评价方案

### 评价维度权重
```yaml
技术实现: 40%  - 游戏功能和体感控制
创新设计: 25%  - 游戏创意和用户体验
团队协作: 20%  - 小组合作和沟通
展示效果: 15%  - 最终展示和表达能力
```

### 评价标准

**🥇 优秀 (90-100分)**
- 体感控制流畅，游戏功能完整
- 游戏有创意，用户体验良好
- 团队协作默契，分工明确
- 展示专业，表达清晰

**🥈 良好 (80-89分)**
- 基础功能实现，偶有小问题
- 游戏设计合理，体验一般
- 团队配合良好，有效沟通
- 展示准备充分，表达基本清晰

**🥉 合格 (60-79分)**
- 核心功能可用，存在明显问题
- 游戏简单，缺少设计
- 团队协作基本正常
- 展示内容完整，表现一般

### 检查清单
```bash
功能检查:
- [ ] 游戏可正常启动和运行
- [ ] 体感控制响应及时（<2秒延迟）
- [ ] 动作识别基本准确（成功率>70%）
- [ ] 游戏逻辑正确（碰撞检测、计分等）
- [ ] 有开始、暂停功能

技术检查:
- [ ] 代码结构基本清晰
- [ ] AI工具使用合理
- [ ] 有基本的调试记录
- [ ] 项目文件组织良好

展示检查:
- [ ] 游戏演示流畅
- [ ] 能清楚介绍游戏特点
- [ ] 能回答同学提问
- [ ] 有项目制作总结
```

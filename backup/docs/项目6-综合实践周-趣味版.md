## 4节课详细安排

### 第1节：🚀 创业启动 - 组队，选赛道，定目标

#### 角色定位
**创业团队** - 每人扮演不同角色

#### 学生视角
"我们像创业公司一样，有CEO、CTO、设计师"

#### 任务流程

**上午：团队组建和项目选择（45分钟）**

1. **跨职能团队组建**（20分钟）
   - **打破原有小组，重新组队**（5-6人/组）
   - **角色分工**：
     - 1人：CEO（产品经理，负责需求和决策）
     - 2人：CTO+工程师（技术开发）
     - 1人：设计师（UI/UX设计）
     - 1人：运营+增长（用户增长、数据分析）
     - 1人：测试+文档（质量保证、文档撰写）

   - **团队破冰**：
     - 介绍自己擅长什么
     - 选出CEO和CTO
     - 起个酷炫的团队名

2. **项目方向投票**（15分钟）
   - 每组选择1个项目方向（从9个中选）
   - 讨论为什么选这个方向
   - 确定目标用户和核心价值

3. **竞品分析**（10分钟）
   - **AI辅助**：
     ```
     ChatGPT Prompt: "我要做一个学习打卡小程序，
     帮我分析竞品：
     1. 番茄TODO、Forest等APP的优缺点
     2. 我们的差异化在哪里（班级互助场景）
     3. 核心竞争力"
     ```

**下午：项目规划（45分钟）**

1. **MVP范围确定**（20分钟）
   - **核心功能** - 必须做（80%时间）
   - **次要功能** - 可以做（20%时间）
   - **未来功能** - 不做（留给下个版本）

   - **AI辅助**：
     ```
     ChatGPT Prompt: "我要在4节课（8小时开发时间）内，
     做一个学习打卡小程序，
     帮我确定MVP范围：
     1. 核心功能清单（必须有）
     2. 功能优先级排序
     3. 开发时间预估
     4. 技术难点分析"
     ```

2. **详细开发计划**（15分钟）
   - **4节课的时间分配**：
     - 第1节（剩余时间）：设计原型 + 技术架构
     - 第2节：核心功能开发（MVP）
     - 第3节：功能完善 + 用户测试
     - 第4节：优化 + 路演准备

   - **任务分配**：
     - CEO：需求文档、用户测试
     - CTO+工程师：技术开发
     - 设计师：UI设计、宣传物料
     - 运营：推广计划、用户增长
     - 测试：测试计划、文档

3. **快速原型设计**（10分钟）
   - Figma快速画出3-5个核心页面
   - 确定技术栈

**交付物**：
- ✅ 项目提案（为什么做、做什么、怎么做）
- ✅ 团队分工表（每人负责什么）
- ✅ 详细开发计划（时间表、里程碑）
- ✅ Figma原型（3-5个核心页面）

## 创业模拟：真实场景

### 场景1：需求变更
**模拟**：第2节开发到一半，CEO突然说"我们要改需求"
**考验**：如何应对需求变更
**解决**：
1. 评估变更成本（时间、工作量）
2. 如果时间不够，拒绝变更或砍其他功能
3. 如果变更合理且可行，快速调整

### 场景2：技术难题
**模拟**：后端遇到技术难题，卡住了
**考验**：如何解决技术难题
**解决**：
1. 团队brainstorm（集思广益）
2. 搜索文档和Stack Overflow
3. 用AI辅助（ChatGPT解决技术问题）
4. 实在不行，降级方案（用更简单的方法实现）

### 场景3：资源冲突
**模拟**：前端需要后端API，但后端还没开发完
**考验**：如何协调资源
**解决**：
1. 前端先用Mock数据（假数据）
2. 约定API接口格式
3. 后端完成后再联调

### 场景4：时间不够
**模拟**：第3节发现功能做不完
**考验**：如何取舍
**解决**：
1. 砍掉非核心功能
2. 保证核心功能可用
3. 质量>数量（宁可少做，不要做烂）

## 路演技巧

### PPT设计技巧
1. **少即是多** - 每页不超过30个字
2. **大图大字** - 用大图和大字吸引注意力
3. **数据可视化** - 用图表代替文字
4. **讲故事** - 用故事开场，引起共鸣

### 演讲技巧
1. **开场吸引注意** - 用痛点或故事开场
2. **语速适中** - 不要太快，不要太慢
3. **眼神交流** - 看着评委和观众
4. **肢体语言** - 自信的姿态，手势辅助
5. **控制时间** - 练习控制在5分钟内

### Q&A技巧
1. **听清问题** - 不懂可以请对方重复
2. **简洁回答** - 不要长篇大论
3. **诚实** - 不知道的问题，诚实说不知道

**技术栈**：React + Python + OCR识别

**路演结果**：最佳技术奖🏆
**学生反馈**："再也不用手抄错题了，省了好多时间！"

### 案例3：智能班牌系统

## 常见问题（FAQ）

### Q1：4节课时间够吗？
**A**：时间很紧张，但这就是创业的真实体验。关键是MVP范围要小，只做核心功能。

### Q2：如果团队有冲突怎么办？
**A**：CEO出面协调。实在不行，投票决定。记住：快速决策比完美决策更重要。

### Q3：如果招不到100个用户怎么办？
**A**：降低标准，50个也可以。重点是展示增长能力和用户反馈。

### Q4：路演紧张怎么办？
**A**：多练习几遍。记住：评委希望你成功，不是来刁难你的。

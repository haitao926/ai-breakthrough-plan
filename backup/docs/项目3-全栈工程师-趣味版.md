## 技术栈选择

### 前端
- **框架**：React + Next.js（最流行的前端框架）
- **UI库**：Tailwind CSS + shadcn/ui（快速开发）
- **状态管理**：Zustand（轻量级）

### 后端
- **框架**：Node.js + Express / Python + FastAPI
- **数据库**：Supabase（开源Firebase）
- **AI集成**：OpenAI API / Claude API

### 部署
- **前端**：Vercel（一键部署，免费）
- **后端**：Railway / Render（免费额度）
- **数据库**：Supabase（云端，免费）

- ✅ **AI友好** - Cursor/Copilot对这些技术支持最好

## AI Coding技巧清单

### 1. 如何写好Prompt？
- ✅ **明确需求**："实现用户登录功能"
- ❌ **模糊需求**："写点代码"

- ✅ **给出上下文**："我用React + Supabase，实现..."
- ❌ **没有上下文**："写个登录"

- ✅ **分步骤**："1. 创建组件 2. 调用API 3. 处理错误"
- ❌ **一次要太多**："帮我做整个网站"

## 常见技术难点和解决方案

### 难点1：API调用跨域问题
**症状**：浏览器报CORS错误
**解决**：后端添加CORS中间件
```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # 生产环境改为具体域名
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### 难点2：环境变量配置
**症状**：API Key泄露，或者本地能跑线上不行
**解决**：用.env文件，Vercel配置环境变量
```
# .env.local
NEXT_PUBLIC_SUPABASE_URL=xxx
NEXT_PUBLIC_SUPABASE_ANON_KEY=xxx
OPENAI_API_KEY=xxx  # 不要加NEXT_PUBLIC_前缀
```

### 难点3：图片上传大小限制
**症状**：上传大图片失败
**解决**：前端压缩图片
```typescript
// 用browser-image-compression库
import imageCompression from 'browser-image-compression';

const options = {
  maxSizeMB: 1,
  maxWidthOrHeight: 1920
}
const compressedFile = await imageCompression(file, options);
```

### 难点4：AI API响应慢
**症状**：等待10秒才有答案
**解决**：添加流式响应（Streaming）
```python
# FastAPI流式响应
async def stream_response():
    for chunk in openai_response:
        yield chunk
```

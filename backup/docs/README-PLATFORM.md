# AI万花筒课程资料平台

## 🚀 快速启动

### 1. 安装依赖
```bash
npm install
```

### 2. 启动服务器
```bash
npm start
```

### 3. 访问平台
- 本地访问：http://localhost:3000
- 局域网访问：http://[你的IP地址]:3000

## 📁 文件结构

### course-files/ 目录说明
```
course-files/
├── project1/          # 项目1-体感互动游戏资料
│   ├── 项目要求.pdf
│   ├── 示例代码.zip
│   └── 教学视频.mp4
├── project2/          # 项目2-产品经理资料
├── project3/          # 项目3-全栈工程师资料
├── project4/          # 项目4-算法工程师资料
├── project5/          # 项目5-嵌入式工程师资料
├── project6/          # 项目6-综合实践资料
└── common/            # 公共资料
    ├── 课程总体设计.pdf
    ├── 工具清单.xlsx
    └── 参考资料.zip
```

## 📚 如何添加课程资料

1. 将课程资料放入对应的 `course-files/projectX/` 目录
2. 刷新网页，资料会自动显示
3. 学生可以直接点击下载

## 🎯 使用场景

### 教师端
1. 上传课程资料到对应目录
2. 在课堂展示给学生
3. 学生扫码或输入IP访问

### 学生端
1. 浏览查看课程介绍
2. 下载所需学习资料
3. 随时随地访问（局域网内）

## 🌐 网络配置

### Windows查看IP
```cmd
ipconfig
```

### Mac/Linux查看IP
```bash
ifconfig
```

让学生访问显示的IPv4地址即可

## 📝 注意事项

1. 确保防火墙允许3000端口
2. 所有设备和教室需要在同一局域网
3. 大文件上传可能需要时间
4. 建议使用Chrome浏览器获得最佳体验

## 🆘 常见问题

**Q: 学生无法访问？**
A: 检查IP地址是否正确，确保在同一WiFi网络

**Q: 文件下载失败？**
A: 检查文件名是否包含特殊字符，建议使用英文和数字

**Q: 如何停止服务？**
A: 按 Ctrl+C 停止服务器

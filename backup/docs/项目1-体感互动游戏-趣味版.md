## 核心技术实现

### 技术栈
- **姿态识别**：MediaPipe / PoseNet（开源AI模型）
- **游戏引擎**：Phaser.js（网页游戏，轻量级）
- **摄像头输入**：笔记本/手机摄像头
- **AI Coding**：Cursor + ChatGPT生成代码

### 技术流程
```
摄像头捕捉玩家画面
    ↓
AI识别身体关键点（头、手、脚等33个点）
    ↓
计算动作类型（跳跃、蹲下、挥手）
    ↓
发送指令到游戏引擎
    ↓
游戏角色响应动作
```

### 关键技术难点
1. **动作识别准确度** - 如何减少误判
2. **延迟优化** - 从动作到游戏响应要快（<100ms）
3. **多人排队体验** - 快速切换玩家
4. **现场光线适应** - 科技节现场光线不同

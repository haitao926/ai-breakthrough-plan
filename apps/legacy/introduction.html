一、课程总体设计

1.1 课程背景

面对人工智能技术的快速发展，传统的“语法驱动”式编程教学已难以满足未来人才的需求。本课程基于“AI 原生 (AI Native)”理念，倡导“人机协作”的工作方式。学生不再是孤立的编码者，而是能够驾驭 AI 工具（如 Cursor, ChatGPT）、具备系统思维和工程能力的创新者。

1.2 教学理念：PBL 项目制学习

本课程彻底摒弃枯燥的理论灌输，采用任务驱动法。全课程包含 6 个递进式项目，覆盖从软件到硬件、从技术到商业的全链路技能。

序号 项目名称 职业角色 核心任务
01 体感互动游戏 交互设计师 利用视觉识别技术开发网页游戏，全面体验 Vibe Coding (AI 辅助编程) 模式。
02 产品与项目管理 产品经理 运用同理心地图和 WBS 工具规划校园产品。
03 全栈工程师 全栈开发者 开发具备前后端交互功能的 Web 应用（错题本）。
04 算法研究 算法研究员 阅读 AI 顶会论文，复现经典模型并进行对比实验。
05 智能硬件 嵌入式工程师 基于树莓派部署 AI 模型，实现软硬结合控制。
06 综合创业实战 联合创始人 组建跨职能团队，完成从 MVP 开发到商业路演的全过程。

二、核心素养培养目标

本课程不仅关注技术技能（Hard Skills），更强调软实力（Soft Skills）的培养。通过“做中学”，重点提升以下能力：

  • AI Coding 能力： 熟练使用 Prompt Engineering 指挥 AI 生成代码、调试 Bug 和重构系统。
  • 工程思维： 建立模块化、低耦合、可测试的代码质量意识。
  • 产品思维： 能够从用户痛点出发，设计具有实际价值的功能（MVP）。
  • 团队协作： 掌握 Git 分支管理，体验敏捷开发 (Agile) 流程。

三、项目一：体感互动游戏 (Vibe Coding)

课时安排： 4 课时

教学目标： 让零基础学生快速建立信心，理解计算机视觉 (CV) 基本原理。

3.1 教学内容详案

课时 主题 关键活动与知识点
L1 视觉引擎启动 1. 理解 MediaPipe 手部 21个关键点 坐标系。
2. 搭建本地 HTTP 服务器，调试摄像头权限。
3. 实战：实时获取食指指尖坐标 (x, y)。
L2 游戏架构搭建 1. 学习 Prompt Engineering：如何向 AI 描述游戏需求。
2. 生成 Phaser.js 游戏原型（跑酷/接金币）。
3. 理解 preload, create, update 游戏循环。
L3 核心交互融合 1. 代码缝合：将 CV 坐标映射为游戏输入。
2. 逻辑编写：if (hand.y < 0.3) { player.jump() }。
3. 调试阈值，解决“误触”与“延迟”问题。
L4 产品发布 1. UX 优化：增加粒子特效、音效、大屏适配。
2. Demo Day：全班展示与互评。

四、项目二：产品与项目管理 (PM & PJM)

课时安排： 4 课时

教学目标： 培养“谋定而后动”的规划能力，掌握互联网产品设计方法论。

4.1 教学内容详案

  • L1 认知重塑： 区分“做正确的事”(PM) 与 “正确地做事”(PJM)。案例分析：为什么食堂的饭菜不好吃？
  • L2 同理心洞察： 使用同理心地图 (Empathy Map) 挖掘用户真实痛点。实战：重新设计学校晚自习体验。
  • L3 结构化思维： 学习 MECE 原则。使用 WBS (工作分解结构) 拆解复杂任务（如元旦晚会策划）。
  • L4 个人成长 PRD： 将自己视为一个产品，运用 PM 思维制定《高中三年通关攻略》，产出个人 PRD 文档。
💡 教学提示： 本单元不涉及代码，重点在于思维训练。鼓励学生使用在线白板工具（如 Miro/FigJam）进行头脑风暴。

五、项目三：全栈工程师实战 (Full Stack)

课时安排： 4 课时

核心产出： 智能错题本 (Mistake Killer) Web 应用

5.1 教学内容详案

课时 内容与步骤
L1 原型设计 (Design)：绘制纸面原型，理解 Client-Server 架构。搭建 HTML 骨架。
L2 前端美化 (Frontend)：使用 Tailwind CSS 或 Flexbox 进行布局。使用 JS 渲染 Mock Data (假数据)，实现界面交互。
L3 后端开发 (Backend)：引入 FastAPI 框架。编写 RESTful API (GET/POST) 接口，实现数据的增删改查。
L4 全栈联调 (Integration)：使用 Fetch API 打通前后端。处理 CORS 跨域问题。最终部署与演示。

六、项目四：算法研究与复现 (Algorithm)

课时安排： 4 课时

教学目标： 祛除 AI 的神秘感，培养科学实验精神与学术素养。

6.1 教学内容详案

L1: 论文侦探 (Paper Reading)

了解 CVPR/ICCV 等顶会。利用 AI 助手辅助阅读经典论文（如 ResNet, YOLO），快速提取核心思想：What problem? How solved?

L2: 复现与推理 (Inference)

不重复造轮子。学习使用 PyTorch Hub 加载预训练模型 (Pre-trained Models)。编写 Python 脚本识别本地图片内容。

L3: 性能优化实验 (Optimization)

设计 A/B Test 对比实验：ResNet50 vs MobileNet。记录推理时间 (Inference Time) 和准确率，理解“精度-速度”的权衡 (Trade-off)。

L4: 学术报告 (Research Report)

撰写包含 IMRaD 结构（引言、方法、结果、讨论）的实验报告。进行微型学术答辩。

七、项目五：智能硬件边缘计算 (IoT)

课时安排： 4 课时

硬件平台： Raspberry Pi 4B / Jetson Nano

7.1 教学内容详案

  • L1 硬件架构师： 认识 GPIO 接口。编写 Python 代码控制 LED 灯闪烁 (Hello World of Hardware)。
  • L2 模型移植： 学习 SSH/SCP 远程连接与文件传输。将 Project 4 训练好的模型部署到树莓派上。
  • L3 软硬联动： 编写逻辑代码：当 AI 识别到“人”时，触发继电器开启风扇或亮灯。实现物理世界的智能控制。
  • L4 产品封装： 配置 Linux 开机自启服务。制作简单的外壳，完成一个脱离电脑独立运行的智能终端。

八、项目六：综合创业实战 (Capstone)

课时安排： 4 课时

形式： 跨职能团队协作 + 黑客马拉松 (Hackathon) 模式

8.1 实战流程

  1. S1 组队与立项 (Startup)： 组建 5-6 人团队，包含 CEO, CTO, Design, Marketing 等角色。从备选库中选择项目（如：校园二手交易平台、智能自习室系统）。
  2. S2 MVP 冲刺 (Sprint)： 采用敏捷开发模式，在 24 小时内（模拟）完成最小可行性产品的核心功能开发。
  3. S3 增长与验证 (Growth)： 将产品投放给真实用户（其他小组同学）。收集反馈数据，快速迭代修复 Bug。
  4. S4 路演日 (Demo Day)： 模拟 IPO 路演。每组进行 8 分钟演讲 + 3 分钟答辩。评审团根据商业价值、技术难度、团队配合打分。

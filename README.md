# 高一学生职业技能培训课程体系 - 网页版

## 📖 概述

这是一个现代化的课程展示网站，用于展示"高一学生职业技能培训课程体系"的完整内容。网站采用响应式设计，支持桌面端和移动端浏览。

## 🚀 快速开始

### 直接打开
1. 双击 `index.html` 文件即可在浏览器中打开
2. 或者将文件拖拽到浏览器窗口中

### 本地服务器运行（推荐）
如果您有本地服务器环境，推荐使用以下方式运行：

```bash
# 使用 Python 3
python -m http.server 8000

# 使用 Node.js
npx serve .

# 使用 PHP
php -S localhost:8000
```

然后在浏览器中访问 `http://localhost:8000`

}

### 修改动画速度
在 CSS 动画定义中调整 `duration` 值：

```css
.card-hover {
    transition: all 0.4s cubic-bezier(0.4, 0, 0.2, 1);
}
```

## 🐛 故障排除

### 常见问题

**Q: 动画效果不流畅？**
A: 检查浏览器是否启用了硬件加速，或者尝试更新浏览器版本。

**Q: 移动端显示异常？**
A: 确保使用的是现代移动浏览器，清除浏览器缓存后重试。

**Q: 链接无法打开？**
A: 确保所有文档文件都在同一目录下，检查文件路径是否正确。

**Q: 字体显示异常？**
A: 检查网络连接，确保 Google Fonts 可以正常加载。

### 调试模式
在浏览器控制台中启用调试模式：

```javascript
localStorage.setItem('debug', 'true');
```

# AI Coding 从入门到实战：体感互动游戏课程设计

## 📅 课程概览

本课程旨在通过"AI辅助编程"（AI Coding）的方式，引导学生从零开始掌握编程逻辑，体验人工智能的强大，并最终完成一个**基于计算机视觉的体感互动游戏**。

**核心理念**：

* **Low Code, High Logic**: 减少语法记忆，重在逻辑表达与Prompt编写。
* **From Python to Web**: 从简洁的Python入手理解算法，过渡到Web技术实现便于传播的交互项目。

## 📝 第二部分：课程教案 (Lesson Plan) - 双线并行设计

**总课时**：4 课时 (每课时 45 分钟)
**双线策略**：

* 📘 **知识主线 (Knowledge Line)**：AI Coding (Prompting / Debugging / Architecture)
* 🚩 **任务主线 (Task Line)**：打造可在大屏展示的科技节互动项目

### 第1课：范式转移 - 视觉引擎启动

* 📘 **知识目标**：掌握 "Prompt Driven Development" (PDD)；理解计算机视觉(CV)坐标系。
* 🚩 **任务推进**：跑通基本的**手势识别Demo**，验证"大屏展示"的可行性。
* **内容**：
  1. **Vision Bootcamp**：使用MediaPipe捕获手部骨架。
  2. **Tech Fest Context**：
     * *思考*：如果放在学校大厅的大屏幕上，手在左上角，屏幕上的光标也必须在左上角吗？
     * *关键调整*：理解 **镜像翻转 (Flip)** 和 **坐标映射** 的重要性。
* **产出**：一个能在大屏上实时跟随手势移动的"光点"。

### 第2课：双雄并立 - 架构搭建

* 📘 **知识目标**：理解 **Client-Server 架构**；使用AI编写 Python WebSocket 服务。
* 🚩 **任务推进**：完成**交互原型**，确定游戏类型。
* **内容**：
  1. **Server Construction**：Python作为"大脑"处理CV数据。
  2. **Game Selection**：选择适合**围观**的游戏类型（动作幅度大、视觉效果好）。
     * *科技节Tips*：小屏幕上精细的操作（如穿针引线）不适合大屏；要选跑酷、切水果这种**大开大合**的。
* **产出**：Python后端 + 基础Web前端，成功握手通信。

### 第3课：数据大动脉 - 核心交互实现

* 📘 **知识目标**：设计数据协议 (JSON Protocol)；解决异步通信逻辑。
* 🚩 **任务推进**：实现**体感控制**，让游戏动起来。
* **内容**：
  1. **Logic Mapping**：将 CV数据 映射为 游戏操作。
  2. **Experience Optimization**：
     * *防误触*：大屏展示时，路人经过会不会干扰？（设置**识别区域/ROI**）。
* **产出**：核心玩法跑通，可以用身体控制的角色。

### 第4课：决战科技节 - 大屏体验优化

* 📘 **知识目标**：工程化思维 (UI Scaling / Error Handling / UX Design)。
* 🚩 **任务推进**：**产品发布**。完成适合大屏体验的最终封装。
* **内容**：
  1. **Big Screen UX (20min)**：
     * **UI巨大化**：AI生成的文字/分数要**大**，让后排观众也能看见。
     * **距离调试**：站在距离摄像头 3-4 米的地方测试，灵敏度是否够？
     * **引导设计**：屏幕闲置时，显示 "请挥手开始" (Call to Action)。
  2. **Showcase (20min)**：
     * **模拟现场**：将电脑投屏到教室大屏，全班轮流体验。
     * **压力测试**：快速换人，系统是否稳定？
* **产出**：一个**抗造、酷炫、适合围观**的科技节互动展品。

## 🌟 核心理念总结

**Coding is Asking.** (编程即提问)
在这个项目中，你不需要背诵复杂的语法，但你需要学会：

1. **清楚地知道自己想要什么** (Define Goal)。
2. **准确地描述给AI听** (Prompting)。
3. **看得懂AI给的结果对不对** (Verification)。
4. **将独立的模块组合成伟大的产品** (Integration).

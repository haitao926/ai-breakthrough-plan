🏗️ 全栈架构总览

全栈开发 = 前端 + 后端 + 数据库

用户界面 | HTML + CSS + JavaScript
⬇️ HTTP 请求 ⬇️

🎨 前端开发 - 什么是前端？

定义

前端就是用户能看到、能点击、能交互的网页界面

前端三剑客

📄 HTML (骨架)

HyperText Markup Language

作用：定义网页结构

比喻：房子的框架

🎨 CSS (皮肤)

Cascading Style Sheets

作用：美化网页样式

比喻：房子的装修

⚡ JavaScript (灵魂)

作用：实现交互逻辑、处理用户操作

比喻：房子的智能家居系统

🎯 前端工程师的使命：让用户用得爽、看得舒服、操作流畅！

📄 HTML - 网页的骨架

HTML 是什么？

HTML 使用标签（Tags）来描述网页的结构

<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <title>智能错题本</title> </head> <body> <h1>我的错题本</h1> <p>这是一个段落</p> <button>点击我</button> </body> </html>

常用 HTML 标签

标签 作用 示例
<h1> ~ <h6> 标题（1最大，6最小） <h1>主标题</h1>
<p> 段落 <p>这是段落</p>
<div> 容器（块级） <div>内容区域</div>
<button> 按钮 <button>提交</button>
<input> 输入框 <input type="text">

🎨 CSS - 网页的美化师

CSS 是什么？

CSS 用来控制网页的样式，包括颜色、字体、布局等

CSS 语法结构

选择器 { 属性: 值; 属性: 值; } /* 示例 */ button { background-color: #3498db; color: white; padding: 10px 20px; border-radius: 5px; }

三种引入方式

1. 内联样式

<p style="color: red">文本</p>

2. 内部样式

<style> p { color: red; } </style>

3. 外部样式 ✅ 推荐

<link rel="stylesheet" href="style.css">

常用 CSS 属性

  • color - 文字颜色
  • background-color - 背景颜色
  • font-size - 字体大小
  • padding - 内边距 | margin - 外边距
  • border - 边框 | border-radius - 圆角

⚡ JavaScript - 网页的灵魂

JavaScript 能做什么？

// 获取元素 let btn = document.getElementById("myBtn"); // 修改内容 btn.textContent = "新文本"; // 修改样式 btn.style.color = "red"; // 绑定事件 btn.addEventListener("click", function() { alert("按钮被点击了！"); });

🌉 前端与后端的桥梁 - HTTP 请求

什么是 HTTP？

HTTP (HyperText Transfer Protocol) 是浏览器和服务器之间的通信协议

HTTP 常用方法

方法 作用 示例场景
GET 获取数据 查询错题列表
POST 创建数据 添加新错题
PUT 更新数据 修改错题内容
DELETE 删除数据 删除错题

前端发送请求 - Fetch API

// GET 请求 - 获取错题列表 fetch("http://localhost:8000/api/mistakes") .then(response => response.json()) .then(data => { console.log("获取到的数据:", data); renderMistakes(data); }) .catch(error => console.error("请求失败:", error));

📤 前端发送 POST 请求 - 添加错题

// POST 请求 - 添加新错题 function addMistake() { const newMistake = { title: document.getElementById("titleInput").value, subject: document.getElementById("subjectInput").value, content: document.getElementById("contentInput").value, answer: document.getElementById("answerInput").value }; fetch("http://localhost:8000/api/mistakes", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(newMistake) }) .then(response => response.json()) .then(data => { alert("添加成功！"); loadMistakes(); // 重新加载列表 }) .catch(error => { alert("添加失败: " + error); }); } // 绑定到按钮 document.getElementById("submitBtn").addEventListener("click", addMistake);
💡 关键点：
  • method: "POST" - 指定请求方法
  • headers - 告诉服务器数据格式是 JSON
  • body - 将 JavaScript 对象转换为 JSON 字符串

⚙️ 后端开发 - 什么是后端？

定义

后端是运行在服务器上的程序，处理业务逻辑、数据存储、权限控制等

🎯 前端

✅ 用户能看到

✅ 运行在浏览器

✅ 负责展示和交互

❌ 不能直接操作数据库

🛠️ 后端

❌ 用户看不到

✅ 运行在服务器

✅ 负责业务逻辑

✅ 直接操作数据库

后端的核心职责

  • 📥 接收前端请求，解析参数
  • 🧠 执行业务逻辑（如数据验证、计算）
  • 💾 操作数据库（增删改查）
  • 📤 返回处理结果给前端
🎯 后端工程师的使命：确保数据安全、逻辑正确、性能高效！

💻 后端实战 - 创建错题 API

from fastapi import FastAPI, HTTPException from pydantic import BaseModel class MistakeCreate(BaseModel): title: str subject: str content: str answer: str @app.post("/api/mistakes") def create_mistake(mistake: MistakeCreate): # 生成新 ID new_id = max([m["id"] for m in fake_db]) + 1 if fake_db else 1 # 创建新错题 new_mistake = { "id": new_id, "title": mistake.title, "subject": mistake.subject, "content": mistake.content, "answer": mistake.answer, "created_at": datetime.now() } # 添加到数据库 fake_db.append(new_mistake) return { "message": "错题添加成功！", "data": new_mistake }

🗄️ 数据库 - 数据的永久存储

为什么需要数据库？

将数据存储在列表变量中，程序关闭后数据就丢失了！

数据库可以持久化存储数据，即使服务器重启，数据依然存在。

SQLite 数据库

  • ✅ 轻量级，无需单独安装服务器
  • ✅ 数据存储在单个文件中（.db 文件）
  • ✅ Python 内置支持，开箱即用
  • ✅ 非常适合小型项目和学习

SQL 语言基础

-- 创建表 CREATE TABLE mistakes ( id INTEGER PRIMARY KEY AUTOINCREMENT, title TEXT NOT NULL, subject TEXT, content TEXT, answer TEXT, created_at DATETIME DEFAULT CURRENT_TIMESTAMP ); -- 插入数据 INSERT INTO mistakes (title, subject, content, answer) VALUES ('三角函数题', '数学', '题目内容', '答案'); -- 查询数据 SELECT * FROM mistakes; -- 删除数据 DELETE FROM mistakes WHERE id = 1;

💻 后端连接数据库 - SQLite 集成

import sqlite3 from fastapi import FastAPI from contextlib import contextmanager app = FastAPI() # 数据库文件路径 DATABASE = "mistakes.db" # 数据库连接上下文管理器 @contextmanager def get_db(): conn = sqlite3.connect(DATABASE) conn.row_factory = sqlite3.Row # 返回字典格式 try: yield conn finally: conn.close() # 初始化数据库表 def init_db(): with get_db() as conn: conn.execute(""" CREATE TABLE IF NOT EXISTS mistakes ( id INTEGER PRIMARY KEY AUTOINCREMENT, title TEXT NOT NULL, subject TEXT, content TEXT, answer TEXT, created_at DATETIME DEFAULT CURRENT_TIMESTAMP ) """) conn.commit() # 启动时初始化数据库 init_db()

💻 完整的 CRUD 操作

@app.get("/api/mistakes") def get_all_mistakes(): with get_db() as conn: cursor = conn.execute("SELECT * FROM mistakes ORDER BY created_at DESC") mistakes = [dict(row) for row in cursor.fetchall()] return mistakes @app.get("/api/mistakes/{mistake_id}") def get_mistake(mistake_id: int): with get_db() as conn: cursor = conn.execute("SELECT * FROM mistakes WHERE id = ?", (mistake_id,)) mistake = cursor.fetchone() if not mistake: raise HTTPException(status_code=404, detail="错题不存在") return dict(mistake) @app.post("/api/mistakes") def create_mistake(mistake: MistakeCreate): with get_db() as conn: cursor = conn.execute( "INSERT INTO mistakes (title, subject, content, answer) VALUES (?, ?, ?, ?)", (mistake.title, mistake.subject, mistake.content, mistake.answer) ) conn.commit() return {"message": "创建成功", "id": cursor.lastrowid} @app.delete("/api/mistakes/{mistake_id}") def delete_mistake(mistake_id: int): with get_db() as conn: conn.execute("DELETE FROM mistakes WHERE id = ?", (mistake_id,)) conn.commit() return {"message": "删除成功"}

🔗 前后端联调 - 打通全流程

跨域问题 (CORS)

⚠️ 问题：前端（localhost:5500）访问后端（localhost:8000）会被浏览器阻止

解决方案：FastAPI 配置 CORS

from fastapi.middleware.cors import CORSMiddleware app = FastAPI() # 配置 CORS app.add_middleware( CORSMiddleware, allow_origins=["*"], # 允许所有来源（生产环境需限制） allow_credentials=True, allow_methods=["*"], # 允许所有 HTTP 方法 allow_headers=["*"], # 允许所有请求头 )

完整开发流程

  1. ✅ 后端：编写 API，测试接口（使用 Postman 或浏览器）
  2. ✅ 前端：编写页面，调用 API
  3. ✅ 联调：前端发起请求，后端返回数据，验证功能
  4. ✅ 测试：模拟各种场景，确保稳定性

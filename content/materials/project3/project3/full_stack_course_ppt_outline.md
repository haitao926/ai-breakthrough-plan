# 课程 PPT 大纲：项目3 - 全栈工程师 (错题本应用开发)

**适用对象**：高一学生
**课程目标**：理解软件开发全流程，掌握基础前后端框架，完成“智能错题本”原型。
**核心隐喻**：学生 = 全栈工程师 = 一个人的特种部队 (一人分饰多角)

---

## 幻灯片 1：封面
**标题**：从 0 到 1：全栈工程师的诞生
**副标题**：项目实战——打造你的“智能错题本”
**配图**：一个超级英雄的剪影，身后是代码矩阵，手中拿着设计图和扳手。

## 幻灯片 2：场景引入 - 痛点在哪里？
**内容**：
- **场景**：考试前夕，试卷满天飞，找不到那道做错的三角函数题？
- **需求**：我们需要一个 App，拍照上传错题，自动分类，随时复习。
- **项目代号**：“Mistake Killer” (错题杀手)

## 幻灯片 3：项目启动会 (Kick-off Meeting)
**角色**：👨‍💼 **项目经理 (Project Manager)**
**台词**：“大家好，虽然我们团队只有你一个人，但我们要像正规军一样战斗！”
**内容**：
- **目标**：4节课内上线 V1.0 版本。
- **关键里程碑 (Milestones)**：
    1.  **Day 1**：需求分析 & 界面草图 (MVP确定)
    2.  **Day 2**：前端构建 (长得好看)
    3.  **Day 3**：后端逻辑 & 数据存储 (脑子好使)
    4.  **Day 4**：联调 & 发布 (由内而外打通)

## 幻灯片 4：蓝图绘制 - 它是长什么样？
**角色**：📝 **产品经理 (Product Manager)**
**台词**：“不要想太复杂，我们先做核心功能。”
**内容 (产品原型图/线框图)**：
- **首页**：错题列表（卡片式展示）。
- **上传页**：上传图片，输入科目、知识点。
- **详情页**：查看答案与解析。
- **交互逻辑**：点击“添加” -> 填写表单 -> 保存 -> 回到列表。

## 幻灯片 5：技术选型 - 选什么武器？
**角色**：🤓 **技术负责人 (Tech Lead)**
**台词**：“我们要选最适合快速开发的工具，不造轮子。”
**内容 (技术栈架构图)**：
- **前端 (Frontend)**：负责“面子”。推荐使用 **Vue.js** (简单易学，组件化) 或 **原生 HTML/JS + Bootstrap** (如果学生基础薄弱)。
- **后端 (Backend)**：负责“里子”。推荐使用 **Python FastAPI** (极简，代码即文档，适合高中生)。
- **数据库 (Database)**：数据的“家”。使用 **SQLite** (轻量级，无需配置) 或 **JSON文件** (最简单的存储)。

## 幻灯片 6：视觉设计 - 要酷！
**角色**：🎨 **UI 设计师 (UI Designer)**
**台词**：“程序员的审美不能只有黑白灰。”
**内容**：
- **配色方案**：清爽蓝（理智）+ 活力橙（重点）。
- **组件规范**：按钮圆角，字体大小，卡片阴影。
- **任务**：将产品经理的草图变成高保真设计图（即使是在纸上画精细一点）。

## 幻灯片 7：制定契约 - API 接口定义
**角色**：🤝 **前后端协商会议**
**内容**：
- **核心概念**：前端和后端怎么“打电话”？—— **HTTP 请求**。
- **接口文档 (API Contract)**：
    1.  `GET /api/mistakes` : 获取所有错题。
    2.  `POST /api/mistakes` : 上传一道新错题。
- **比喻**：去餐厅点菜。菜单是API文档，服务员是HTTP请求，后厨是后端，菜是数据。

## 幻灯片 8：前端开发 - 搭建骨架
**角色**：💻 **前端工程师 (Frontend Developer)**
**任务**：
- 编写 HTML 结构。
- 编写 CSS 美化。
- 编写 JS 处理点击事件，准备发送请求。
- **演示**：一个只有界面，数据是写死（Mock）的网页。

## 幻灯片 9：后端开发 - 注入灵魂
**角色**：⚙️ **后端工程师 (Backend Developer)**
**任务**：
- 接收前端发来的数据。
- 逻辑处理（比如统计这是数学第几次做错了）。
- 存入数据库。
- 返回“保存成功”。

## 幻灯片 10：测试与验收 - 找茬时间
**角色**：🐞 **测试工程师 (QA)**
**台词**：“相信我，绝对有 Bug。”
**内容**：
- **测试用例**：
    - 不上传图片能不能提交？
    - 标题写特别长会怎么样？
    - 只有前端没有后端，报错是什么样？
- **Debug**：全栈工程师的必备技能——看控制台 (Console) 和 日志 (Log)。

## 幻灯片 11：全栈工程师 (Full Stack Engineer)
**总结**：
- **定义**：全栈不是“什么都懂一点”，而是“**有能力独立解决端到端的问题**”。
- **价值**：能够从全局视角理解系统，沟通成本最低，创造力最高。
- **你的任务**：在这 4 节课里，你将独自一人，完成这支团队的所有工作！

**内容**：
- 打开 VS Code。
- 建立项目文件夹 `mistake-killer`。
- 第一行代码，即将开始...

🤝 制定契约：API

前端和后端怎么“对话”？ --> HTTP 协议

就像去餐厅点菜：

  • 菜单 = API 文档
  • 服务员 = HTTP 请求
  • 后厨 = 后端程序

GET /api/mistakes : 把所有错题端上来

POST /api/mistakes : 厨房，做道新菜（保存错题）

⚙️ 后端开发

后端开发


from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

# 定义数据结构
class Mistake(BaseModel):
    subject: str
    description: str

# 只有几行代码，一个服务器就跑起来了
@app.post("/api/mistakes")
def create_mistake(mistake: Mistake):
    save_to_file(mistake)
    return {"status": "ok", "msg": "已保存"}

📈 运营 (Operations)

运营

第一性原理：生命周期管理

  • 冷启动 (Cold Start)：没人用怎么办？先拉 5 个学霸当“托”。
  • DAU (日活)：下载量不重要，重要的是多少人天天用。
  • 私域流量：把用户拉进“错题互助群”，随时触达。

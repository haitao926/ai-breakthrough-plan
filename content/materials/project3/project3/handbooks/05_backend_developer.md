# ⚙️ 后端工程师 (Backend) 黑话指南

**核心奥义**：**逻辑与持久化**。
**第一性原理**：**输入 -> 处理 -> 输出 (I/O)**。
任何计算机程序本质上都是一个函数：接受外部输入（前端请求），经过逻辑处理（计算/读写），产生输出（响应结果）。后端是这个过程的守护者。

---

### 1. 接口 (API)
*   **黑话定义**：服务窗口。
*   **第一性原理**：**封装与契约 (Encapsulation & Contract)。**
    就像去银行办事，你不需要知道柜员怎么操作电脑，你只需要在这个“窗口”递进去身份证（参数），就能拿回钱（数据）。接口屏蔽了复杂的内部逻辑。
*   **怎么做**：定义好 URL（如 `/api/upload`），告诉前端：往这里发图片，我就给你存好。

### 2. 持久化 (Persistence)
*   **黑话定义**：存盘。
*   **第一性原理**：**易失性 vs 永久性。**
    内存（RAM）像黑板，写得快但断电就没（易失）；硬盘（Disk）像石碑，刻得慢但能存千年（永久）。后端要把数据从内存这块黑板搬到硬盘这座石碑上。
*   **怎么做**：把接收到的错题数据，写入文件（JSON）或者数据库（SQLite）里。

### 3. JSON
*   **黑话定义**：数据普通话。
*   **第一性原理**：**序列化 (Serialization)。**
    Python 有 Python 的对象，JS 有 JS 的对象，语言不通。JSON 是一种基于文本的通用格式，就像“英语”，所有编程语言都读得懂。
*   **怎么做**：后端把数据打包成 JSON 发出去，前端收到解包。

### 4. 路由 (Route)
*   **黑话定义**：指路牌。
*   **第一性原理**：**分发机制 (Dispatch)。**
    超市有生鲜区、日用品区。请求来了，谁来处理？路由就是那个导购员：“买菜的去左边（`/user`），买肉的去右边（`/order`）”。
*   **怎么做**：`@app.get("/hello")` —— 凡是访问 `/hello` 的，都由下面这个函数接待。

### 5. 状态码 (Status Code)
*   **黑话定义**：红绿灯。
*   **第一性原理**：**协议握手。**
    不仅要说话，还要表达态度。
    *   **200**：成功（OK）。
    *   **404**：找不到（你瞎写的地址）。
    *   **500**：服务器炸了（我的锅）。
*   **怎么做**：看到 200 就放心，看到 500 就赶紧查后端代码报错。

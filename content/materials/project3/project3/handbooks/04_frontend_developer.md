# 🖼️ 前端工程师 (Frontend) 黑话指南

**核心奥义**：**即时渲染**。
**第一性原理**：**光子与视网膜的交互**。
前端的本质是将抽象的二进制数据（0和1），翻译成人类眼睛能接收的光信号（像素），并捕捉人类的手部动作（点击、滑动）反馈给系统。

---

### 1. 结构/表现/行为分离
*   **黑话定义**：三驾马车。
*   **第一性原理**：**关注点分离 (Separation of Concerns)。**
    就像盖房子：
    *   **HTML** 是钢筋混凝土（结构，决定是房子还是桥）。
    *   **CSS** 是装修涂料（表现，决定好不好看）。
    *   **JS** 是智能家居系统（行为，决定能不能动）。
    混在一起会变成难以维护的“屎山”。
*   **怎么做**：HTML 写内容，CSS 写样式，JS 写逻辑，各司其职。

### 2. DOM (文档对象模型)
*   **黑话定义**：网页的族谱。
*   **第一性原理**：**树状结构 (Tree Structure)。**
    浏览器把网页看作一棵倒过来的树。`<html>` 是根，`<body>` 是树干，`<div>` 是树枝，`<img>` 是叶子。修改网页，就是修剪这棵树。
*   **怎么做**：用 JS 找到这棵树上的某个叶子（`getElementById`），然后把它变成红色。

### 3. HTTP 请求 (Request)
*   **黑话定义**：飞鸽传书。
*   **第一性原理**：**跨空间通信协议。**
    前端（你的浏览器）和后端（服务器）往往相隔千里。它们之间需要一套标准的“信件格式”来交流。
    *   **GET**：我要读信（获取数据）。
    *   **POST**：我给你写信（发送数据）。
*   **怎么做**：前端不管数据怎么存，只管发个请求过去“要”数据。

### 4. 渲染 (Rendering)
*   **黑话定义**：画出来。
*   **第一性原理**：**数据可视化。**
    数据是冰冷的 JSON（`{score: 59}`），渲染是把它变成鲜红的文字“59分”。前端工程师就是数据的“翻译官”。
*   **怎么做**：拿到后端给的数据列表，用循环（Loop）把它变成一个个 HTML 卡片。

### 5. 调试 (Console Log)
*   **黑话定义**：F12 大法。
*   **第一性原理**：**可观测性 (Observability)。**
    程序在浏览器肚子里运行，你看不到它的思考过程。`console.log` 就像给程序装了个X光机，把它的内心独白打印在屏幕上。
*   **怎么做**：不知道哪里出错了？在代码里到处写 `console.log(变量名)`，看看它到底变成了什么。

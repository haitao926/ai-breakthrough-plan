# 💰 销售 (Sales) 黑话指南

**核心奥义**：**价值变现**。
**第一性原理**：**价值交换 (Value Exchange)**。
商业的本质是交换。用户之所以愿意掏钱（让渡价值），是因为你提供的产品解决了他的问题，让他觉得“物超所值”。销售不是忽悠，而是把“产品的价值”翻译成“客户的收益”，并建立信任的桥梁。

---

### 1. To B / To C
*   **黑话定义**：卖给谁。
*   **第一性原理**：**决策机制的差异。**
    *   **To C (Consumer)**：卖给个人。决策快，看心情，重体验。比如卖奶茶、卖游戏皮肤。
    *   **To B (Business)**：卖给企业/学校。决策慢，看流程，重效率和降本。比如把错题本系统卖给全校使用。
*   **怎么做**：To C 讲“好用、爽”；To B 讲“能提高全校平均分 5%”。

### 2. 电梯演讲 (Elevator Pitch)
*   **黑话定义**：30秒定生死。
*   **第一性原理**：**注意力稀缺与信息压缩。**
    在这个信息爆炸的时代，重要人物（投资人、校长）的注意力极其宝贵。你必须在坐电梯的 30 秒内，用最精炼的语言讲清楚“你是谁、解决什么问题、有什么优势”。
*   **怎么做**：练习话术——“我们的[错题杀手]能让学生[告别手抄]，每天[节省30分钟]，已经在[高一3班]验证成功。”

### 3. 痛点营销 (Pain Point Marketing)
*   **黑话定义**：伤口撒盐（然后卖创可贴）。
*   **第一性原理**：**损失厌恶 (Loss Aversion)。**
    心理学研究表明，人对于“避免损失”的动力远大于“获得收益”。与其说“这个产品能帮你考满分”（收益），不如说“不用这个产品，你会浪费多少复习时间”（损失）。
*   **怎么做**：描述惨状：“你还在因为找不到试卷而焦虑吗？还在因为抄错题抄断手吗？” -> 递上解药：“用错题杀手，一键解决。”

### 4. 竞品分析 (Competitor Analysis)
*   **黑话定义**：知己知彼。
*   **第一性原理**：**生态位 (Niche)。**
    市场上很少有完全空白的领域。了解对手（别的错题App、甚至手抄本），是为了找到自己的“差异化优势”——也就是你活下去的理由。
*   **怎么做**：列个表。对手 A：功能强但收费贵；对手 B：免费但广告多；我们：极简、无广告、专注高中数学。

### 5. 转化率 (Conversion Rate)
*   **黑话定义**：漏斗。
*   **第一性原理**：**概率筛选。**
    并不是所有看到你产品的人都会买。
    100 个人看到宣传单（曝光） -> 20 个人扫码（点击） -> 5 个人注册（激活） -> 1 个人付费（转化）。
    销售的核心就是把这个漏斗修得更宽。
*   **怎么做**：如果扫码的人多但注册的人少，说明注册流程太麻烦（门槛太高），要去优化它。

# 👁️ UI 设计师 (UI) 黑话指南

**核心奥义**：**降低认知负荷**。
**第一性原理**：**大脑是认知吝啬鬼**。
人类大脑处理视觉信息需要消耗能量。好的设计就是让大脑“不用思考”也能瞬间看懂（Don't Make Me Think）。任何让人迟疑的设计都是在消耗用户的脑力。

---

### 1. 视觉层级 (Visual Hierarchy)
*   **黑话定义**：谁是老大。
*   **第一性原理**：**注意力聚焦。**
    人的眼睛无法同时看清所有东西。我们需要通过大小、颜色、粗细的反差，来告诉眼睛：先看这里（标题），再看那里（按钮）。
*   **怎么做**：把最重要的内容（比如“上传按钮”）做大、做亮；把次要内容（比如“日期”）做小、做灰。

### 2. 留白 (White Space)
*   **黑话定义**：呼吸感。
*   **第一性原理**：**格式塔心理学（分组原则）。**
    距离近的物体会被大脑认为是一组的。留白不是浪费空间，而是用“空”来划分“有”，用距离来表达逻辑关系。
*   **怎么做**：别把东西塞满！给每个元素周围留出至少 20px 的空白，让页面“透透气”。

### 3. 一致性 (Consistency)
*   **黑话定义**：长得像一家人。
*   **第一性原理**：**模式识别与学习成本。**
    如果第一页的确认按钮是绿色的，第二页变成了红色，大脑就需要重新学习规则。保持一致能利用用户的惯性，降低学习成本。
*   **怎么做**：所有的标题字号一样大，所有的按钮圆角一样圆，所有的颜色用同一套。

### 4. 响应式 (Responsive)
*   **黑话定义**：能伸能缩。
*   **第一性原理**：**容器适应性。**
    水在杯子里是杯子的形状，在壶里是壶的形状。内容（水）应该适应屏幕（容器），而不是让容器去适应内容。
*   **怎么做**：不要把宽度写死（`width: 800px`），要用百分比（`width: 100%`），让它自己适应手机和电脑。

### 5. 色彩心理学 (Color Psychology)
*   **黑话定义**：颜色会说话。
*   **第一性原理**：**进化心理学与情绪触发。**
    红色在自然界代表危险（血、火），所以用来表示“删除”、“错误”；绿色代表生机，用来表示“成功”、“通行”。这是刻在基因里的本能。
*   **怎么做**：提交用绿色/蓝色，删除/报错用红色，普通文字用黑灰色。

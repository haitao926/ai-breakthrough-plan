🧐 什么是 Git?

Git 是代码的时光机。

  • 写崩了？👉 一键回滚到昨天。
  • 误删了？👉 从历史记录里找回。
  • 多人写？👉 自动合并大家的代码。

🚀 快速上手 (网页版)

  1. 注册：点击右上角，组长和组员都注册。
  2. 建库：组长点击 创建仓库。
  3. 邀请：设置 -> 协作者 -> 添加组员。
  4. 上传：直接在网页点击“上传文件”。
⚠️ 警告：严禁把包含密码的文件传上去！

🔥 进阶：黑客模式 (命令行)

在终端输入这三行，你就入门了：


git add .               # 1. 把所有文件打包放入“发货箱”
git commit -m "更新UI"   # 2. 贴上封条，写清楚改了什么
git push                # 3. 让快递员把箱子送到服务器

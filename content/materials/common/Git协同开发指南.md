# 🤝 极简 Git 协同开发指南
> "如果代码没有版本控制，就像写作业不用橡皮擦。" —— 匿名全栈工程师

## 1. 什么是 Git？
Git 是一个**时光机**。
*   它能记录你代码的每一次修改。
*   如果改错了，随时可以“穿越”回过去。
*   它能让多人同时修改一个项目，最后把大家的成果“合并”在一起。

我们在课堂上部署了 **Gitea**（校内版 GitHub），供大家托管代码。

---

## 2. 快速开始 (3分钟上手)

### 第一步：注册账号
1. 访问教师机提供的地址（通常是 `http://192.168.x.x:3000`）。
2. 点击右上角 **注册**。
3. 这里的账号仅在局域网有效。

### 第二步：创建仓库 (仅需组长操作)
1. 点击右上角 `+` -> **创建仓库**。
2. 仓库名称：建议用项目名，如 `Project6-TeamA`。
3. 勾选 **初始化仓库** (添加 README)。
4. 点击 **创建仓库**。
5. **邀请成员**：进入 `设置` -> `协作者`，把你的组员都加进来。

### 第三步：上传代码 (Web方式 - 最简单)
如果你不想用命令行，可以直接在网页上操作：
1. 进入你的仓库。
2. 点击 **上传文件** 按钮。
3. 把你的代码文件拖进去，写一句“提交信息”（例如：完成了首页UI），点击提交。

## 3. 进阶：像黑客一样使用命令行 (推荐)

如果你想体验真正的全栈工程师工作流，请尝试使用终端。

### 0. 第一次配置 (每台电脑只需做一次)
打开终端 (Terminal) 或 Git Bash，输入：
```bash
git config --global user.name "你的名字"
git config --global user.email "yourname@example.com"
```

### 1. 克隆代码 (Clone)
把服务器上的代码下载到本地：
```bash
# 复制仓库页面上的 HTTP 链接
git clone http://192.168.x.x:3000/你的用户名/仓库名.git
```

### 2. 提交三部曲 (Daily Workflow)
每天写完代码，执行这三步：

**① 打包 (Add)**
```bash
git add .
# 把所有修改过的文件放到“发货箱”里
```

**② 贴标签 (Commit)**
```bash
git commit -m "这里写你干了什么，比如：修复了登录Bug"
# 给发货箱贴上封条，写上说明
```

**③ 发货 (Push)**
```bash
git push
# 把箱子送到服务器，队友就能看见了
```

### 3.以此类推 (Pull)
每天开工前，先拉取队友的最新代码：
```bash
git pull
```

---

## 4. 遇到冲突怎么办？(Conflict)
如果你和队友修改了同一个文件的同一行，Git 会报错：“冲突 (Conflict)”。
这不是坏事，说明你们都很努力！

**解决方法**：
1. 打开报错的文件。
2. 你会看到 `<<<<<<<` 和 `>>>>>>>` 的标记。
3. 手动删除你不想要的代码，保留正确的。
4. 再次执行 **提交三部曲**。

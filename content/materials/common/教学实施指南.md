# 教学实施指南 - 高一职业技能培训课程

## 📋 概述

本指南为教师提供详细的课程实施方法、教学技巧和注意事项，确保课程顺利开展并达到预期效果。

---

## 🎯 教学目标

### 核心目标
1. **培养AI时代核心能力** - AI Coding + 任务规划
2. **体验6种职业角色** - 发现学生兴趣和优势
3. **完成6个真实项目** - 建立成就感和技术自信
4. **提升综合素养** - 协作、沟通、表达能力

### 具体目标
- 掌握AI工具辅助开发的基本方法
- 学会产品思维和项目管理流程
- 具备全栈开发的基础能力
- 了解算法研究和硬件开发流程
- 培养创业思维和团队协作能力

---

## 📚 课程准备

### 教师准备
#### 技能要求
- **必备技能**：
  - 基础编程知识（JavaScript/Python）
  - 熟悉AI工具使用（ChatGPT, Cursor）
  - 了解Web开发基础
  - 具备项目管理基本概念

- **推荐技能**：
  - 熟悉游戏开发
  - 了解机器学习基础
  - 有硬件开发经验
  - 具备创业指导经验

#### 课前准备
1. **熟悉所有项目文档**
   - 仔细阅读6个项目详细文档
   - 理解每个项目的技术要求和教学重点
   - 准备项目演示demo

2. **测试开发环境**
   - 确保所有软件工具正常工作
   - 测试AI工具的可用性
   - 准备备用方案（网络问题等）

3. **准备教学材料**
   - PPT演示文稿
   - 项目案例和素材
   - 评估标准和检查清单

### 学生准备
#### 基础要求
- 具备基本的计算机操作能力
- 对新技术有好奇心和学习意愿
- 团队协作意识和沟通能力

#### 推荐准备
- 有一定编程基础（非必需）
- 对某个技术领域有特殊兴趣
- 具备英语阅读能力（看技术文档）

### 设备和环境
#### 硬件要求
- **每组设备**：
  - 电脑（Windows/Mac/Linux均可）
  - 稳定的网络连接
  - 摄像头（课程1、5需要）
  - 麦克风（路演和演示）

- **公共设备**：
  - 投影仪或大屏幕
  - 稳定的WiFi网络
  - 打印机（文档打印）
  - 实验桌和椅子

#### 软件要求
- **必备软件**：
  - 现代浏览器（Chrome/Firefox）
  - 代码编辑器（VS Code推荐）
  - Git版本控制工具

- **在线工具**：
  - ChatGPT账号
  - GitHub账号
  - Figma账号

## 📖 教学流程

### 课程整体安排
```
24节课 = 6个项目 × 4节课/项目
每节课90分钟 = 15分钟理论 + 60分钟实践 + 15分钟总结
```

### 标准教学流程

#### 课前准备（10分钟）
1. 检查教室环境和设备
2. 开启必要的软件和网站
3. 准备演示材料
4. 检查学生出勤情况

#### 课程开始（5分钟）
1. 回顾上节课内容
2. 宣布本节课目标
3. 激发学生兴趣

#### 理论讲解（15-20分钟）
1. 核心概念介绍
2. 技术要点讲解
3. 案例分析演示
4. Q&A环节

#### 实践操作（60分钟）
1. 任务布置和分组
2. 学生动手实践
3. 教师巡回指导
4. 解决技术难题

#### 总结反思（10分钟）
1. 成果展示
2. 经验分享
3. 问题总结
4. 下节课预告

## 🎮 项目1：体感互动游戏 - 教学要点

### 教学重点
- **AI工具入门**：首次使用ChatGPT生成代码
- **游戏开发基础**：理解游戏循环和事件处理
- **姿态识别**：MediaPipe的基本使用
- **成就感建立**：快速看到成果

### 教学难点
- 学生对编程的恐惧心理
- AI工具的正确使用方法
- 游戏逻辑的理解

### 解决方案
- 强调AI工具的辅助作用
- 提供详细的操作步骤
- 鼓励学生大胆尝试

### 时间分配
- 第1节：MediaPipe基础 + 姿态识别
- 第2节：游戏框架搭建 + AI生成代码
- 第3节：游戏逻辑实现 + 测试优化
- 第4节：界面美化 + 演示准备

## 💰 项目2：产品经理+项目经理 - 教学要点

### 教学重点
- **用户调研方法**：如何进行有效访谈
- **产品设计思维**：用户需求到产品功能
- **项目管理基础**：WBS和敏捷开发
- **表达能力**：向他人清晰展示方案

### 教学难点
- 从用户需求中挖掘真实痛点
- 产品功能的优先级排序
- 项目计划的合理性

### 解决方案
- 提供调研模板和示例
- 使用AI工具辅助分析
- 案例分析和对比

### 实践活动
- 校内用户调研（真实场景）
- 竞品分析（实际产品）
- 原型设计（Figma实践）
- 路演练习（演讲技巧）

## 🌐 项目3：全栈工程师 - 教学要点

### 教学重点
- **前后端分离**：理解现代Web架构
- **数据库设计**：基本的数据建模
- **API开发**：RESTful接口设计
- **部署上线**：从开发到生产

### 教学难点
- 前后端数据交互
- 数据库操作的理解
- 部署过程的复杂性

### 解决方案
- 使用AI工具生成代码框架
- 提供详细的部署教程
- 逐步分解复杂任务

### 技术栈教学
- **前端**：React + Tailwind CSS
- **后端**：Node.js + Express
- **数据库**：Supabase
- **部署**：Vercel + Railway

## 🧠 项目4：算法工程师 - 教学要点

### 教学重点
- **学术研究方法**：如何阅读和理解论文
- **算法思维**：问题分析和解决方案设计
- **实验设计**：科学验证算法效果
- **学术写作**：研究报告的撰写

### 教学难点
- 论文中复杂概念的理解
- 算法实现的难度
- 实验结果的分析

### 解决方案
- 选择适合高中生的论文
- 使用AI工具辅助代码实现
- 提供实验模板

### 论文选择建议
- **推荐主题**：图像识别、推荐系统、游戏AI
- **避免主题**：需要复杂数学推导的论文
- **教学重点**：理解思路，不纠结细节

---

## 🔧 项目5：嵌入式工程师 - 教学要点

### 教学重点
- **硬件基础**：电路原理和传感器使用
- **软硬件结合**：算法在硬件上的实现
- **系统集成**：多个模块的协调工作
- **实物演示**：从虚拟到现实的体验

### 教学难点
- 硬件开发的复杂性
- 调试难度大
- 需要动手能力

### 解决方案
- 提供详细的硬件教程
- 使用现成的模块减少复杂性
- 准备备用器件

### 安全注意事项
- 用电安全教育
- 器件保护意识
- 环境整洁要求

---

- **商业计划**：简单的商业模式设计
- **投资路演**：模拟融资演示

## 👥 团队管理

### 分组策略
- **项目1-5**：3-4人固定小组
- **项目6**：5-6人跨职能团队

### 角色分配
- **项目经理**：进度协调和决策
- **技术负责人**：技术选型和实现
- **设计师**：UI/UX设计
- **开发工程师**：编码实现
- **测试人员**：质量保证

### 冲突处理
- **预防措施**：明确分工，定期沟通
- **解决方法**：及时调解，寻求共识
- **升级机制**：教师介入协调

## 📊 评估体系

### 评估维度
1. **过程性评估**（50%）
   - 任务规划质量（10%）
   - 学习日志完整性（10%）
   - 团队协作表现（15%）
   - 课堂参与度（15%）

2. **成果性评估**（50%）
   - 项目完成度（20%）
   - 技术创新性（15%）
   - 文档规范性（10%）
   - 最终展示（5%）

### 评估工具
- **检查清单**：每个项目的完成标准
- **评分量表**：能力维度的量化评估
- **同伴评价**：团队成员互评
- **自我反思**：学生自我评估

### 反馈机制
- **即时反馈**：课堂上的及时指导
- **定期反馈**：每周的进度反馈
- **总结反馈**：项目结束的综合评价

## 🔧 常见问题处理

### 技术问题
1. **AI工具无法访问**
   - 准备备用AI工具
   - 提供离线代码模板
   - 教师手动协助

2. **代码运行错误**
   - 使用AI调试工具
   - 逐步排查问题
   - 寻求同学帮助

3. **网络连接问题**
   - 准备离线资料
   - 使用手机热点
   - 调整教学计划

### 学习问题
1. **学生学习进度差异**
   - 分层任务设计
   - 同伴互助机制
   - 个性化指导

2. **学生兴趣不高**
   - 调整项目主题
   - 增加趣味元素
   - 及时鼓励激励

3. **团队协作困难**
   - 明确角色分工
   - 建立沟通机制
   - 教师及时介入

打开你电脑上的 **终端 (Terminal)** 或 **Git Bash**，输入以下命令把仓库“搬”到你的电脑上：

```bash
# 💡 提示：把下面的链接换成你仓库的实际地址
git clone http://10.20.216.183:3000/你的用户名/仓库名称.git
```
*输入账号密码时，光标可能不会移动，这是正常的，输完按回车即可。*

## 🔄 第四步：每日开发三部曲
每天写代码前，先获取队友的更新；写完后，把你的成果传上去。

### 1. 开工前：拉取最新代码
```bash
git pull
```

### 2. 收工时：提交三连击
当你完成了一个功能或修改了代码：

**① 打包 (Add)** - 把修改过的文件放到“发货箱”
```bash
git add .
```

**② 贴标签 (Commit)** - 说明你干了什么
```bash
git commit -m "这里写清楚你做了什么，比如：增加了游戏背景音乐"
```

**③ 发货 (Push)** - 推送到服务器
```bash
git push
```

## ❓ 常见问题救急

**Q: 提交时报错 `Conflict` (冲突) 怎么办？**
> A: 这说明你和队友修改了同一个文件的同一行。
> 1. 打开报错的文件，找到 `<<<<<<<` 和 `>>>>>>>` 标记。
> 2. 和队友商量，手动删除多余的代码，保留正确的。
> 3. 保存文件，重新执行“提交三连击”。

**Q: 忘记密码怎么办？**
> A: 请直接联系老师在后台重置。

**Q: 提示 `Authentication failed`？**
> A: 账号或密码输错了。请重新输入，注意大小写。

## 📝 第1课：硬件架构师 (System Design)

### 🎯 教学目标
1.  理解 **IoT** (物联网) 与 **边缘计算** 架构。
2.  认识开发板接口 (GPIO, USB, HDMI)。
3.  **产出**：硬件系统连接图。

### ⏱️ 教学流程

#### 0-10分钟：从云端到边缘
*   **提问**："Siri 是在你的手机里运行，还是在苹果服务器里？" (服务器)。
*   **痛点**：如果断网了怎么办？如果为了隐私不想上传照片怎么办？
*   **概念**：**边缘计算 (Edge Computing)** —— 把大脑装进设备里。

#### 10-25分钟：认识你的武器 (Raspberry Pi)
*   **实物展示**：
    *   **CPU**：大脑。
    *   **GPIO (40-pin)**：神经末梢（控制灯、电机）。
    *   **USB**：眼睛（摄像头）接口。
*   **任务**：画出你的"智能相机"连接图。
    *   摄像头 -> USB口。
    *   LED灯 -> GPIO 17号引脚。

#### 25-45分钟：点亮第一盏灯 (Hello World)
*   **连接**：指导学生正确连接 LED 灯（长脚接正，串联电阻）。
*   **代码**：
    ```python
    import RPi.GPIO as GPIO
    import time
    GPIO.setmode(GPIO.BCM)
    GPIO.setup(17, GPIO.OUT)
    
    while True:
        GPIO.output(17, GPIO.HIGH) # 亮
        time.sleep(1)
        GPIO.output(17, GPIO.LOW)  # 灭
        time.sleep(1)
    ```
*   **现象**：灯闪烁。恭喜，你打通了软件与硬件的屏障！

## 📝 第2课：模型移植 (Deployment)

### 🎯 教学目标
1.  掌握 **SCP/SFTP** 文件传输方法。
2.  理解 **环境依赖** (Library Dependencies)。
3.  **产出**：在树莓派上成功运行图像识别脚本。

### ⏱️ 教学流程

#### 0-10分钟：搬家
*   **场景**：我们在电脑上训练好了模型 (Project 4)，现在要把它搬到树莓派上。
*   **工具**：FileZilla 或 VS Code Remote SSH。

#### 10-30分钟：环境配置与传输
*   **任务 1**：将电脑上的 `resnet_model.pth` 和 `inference.py` 传到树莓派的 `/home/pi/ai_project` 目录。
*   **任务 2**：在树莓派终端尝试运行。
    *   `python3 inference.py`
    *   **报错预演**：`ModuleNotFoundError: No module named 'torch'`.
    *   **解决**：使用预装好的环境或 `pip install` (注意树莓派架构是 ARM，不能随便 pip，最好用系统包管理器)。

#### 30-45分钟：实时推理
*   **修改代码**：将读取本地图片改为读取摄像头视频流。
    ```python
    import cv2
    cap = cv2.VideoCapture(0)
    ret, frame = cap.read()
    # ... 预处理 frame ...
    # ... 模型推理 ...
    print(prediction)
    ```
*   **挑战**：观察 FPS (每秒帧数)。是不是比电脑慢很多？(这就是嵌入式开发的挑战)。

## 📝 第3课：软硬联动 (Integration)

### 🎯 教学目标
1.  将 **AI 识别结果** 转换为 **GPIO 信号**。
2.  实现逻辑控制（If Person detected -> Light ON）。
3.  **产出**：智能感应灯原型。

### ⏱️ 教学流程

#### 0-10分钟：赋予灵魂
*   **逻辑设计**：
    *   摄像头一直在看。
    *   AI 一直在算。
    *   如果 (识别结果 == "Person" 且 置信度 > 0.8):
        *   开灯 (GPIO HIGH)
    *   否则:
        *   关灯 (GPIO LOW)

#### 10-40分钟：代码融合
*   **任务**：将第1课的 GPIO 代码和第2课的 AI 代码合并。
*   **AI 辅助**：
    *   Prompt: "我有两段 Python 代码，一段控制树莓派 LED 亮灭，一段用 PyTorch 识别图片。请帮我合并，实现功能：当识别到 'cup' (杯子) 时，点亮 LED 灯，否则熄灭。"
*   **调试**：
    *   拿着杯子在摄像头前晃动，观察 LED 反应。
    *   调整识别频率（不需要每秒 30 次，每秒 2 次即可，节省 CPU）。

#### 40-45分钟：效果演示
*   **展示**：每组展示自己的触发逻辑（识别水瓶亮灯、识别手机亮灯等）。

## 📝 第4课：产品封装 (Productization)

### 🎯 教学目标
1.  了解 **自动运行** (Autostart) 配置。
2.  思考产品的 **交互设计** (UI/UX)。
3.  **产出**：开机即用的智能硬件作品。

### ⏱️ 教学流程

#### 0-15分钟：脱离电脑
*   **问题**：现在的设备必须连着显示器敲命令才能跑。真正的产品是插电就用的。
*   **实操**：配置 `systemd` 服务或 `rc.local`，让 Python 脚本开机自启。
    *   `sudo nano /etc/rc.local`
    *   添加 `python3 /home/pi/ai_project/main.py &`

#### 15-35分钟：外壳与交互
*   **外壳制作**：使用乐高积木、纸板或 3D 打印件制作外壳，固定摄像头和树莓派。
*   **交互优化**：
    *   加一个按钮：按下按钮才识别（省电模式）。
    *   加一个蜂鸣器：识别成功 "滴" 一声。

#### 35-45分钟：最终路演
*   **模拟发布会**：
    *   "这是我们组开发的智能垃圾分类助手..."
    *   现场演示投放垃圾，灯光指示分类。
*   **总结**：你们现在已经是全栈 + 嵌入式工程师了！

## 🛠️ 常见问题 (Troubleshooting)

1.  **摄像头打不开 (cv2.VideoCapture(0) fail)**
    *   **检查**：树莓派配置中是否启用了 Camera 接口 (`sudo raspi-config`)。
    *   **检查**：USB 是否插紧，供电是否充足。

2.  **程序运行极慢，卡死**
    *   **原因**：模型太大，内存爆了。
    *   **解决**：换用 MobileNet (Project 4 讲过的优化)，或者减小输入图片的分辨率 (e.g., 224x224)。

3.  **LED 灯不亮**
    *   **检查**：LED 正负极是否接反？
    *   **检查**：GPIO 引脚号是否对应（BCM 编码 vs BOARD 编码）。

# 实战案例与学生作业单

## 模块一：产品经理实战 —— 洞察需求，解决痛点
**核心口号**：不要因为手里有锤子，看什么都是钉子。（不要为了做而做，要看用户真正需要什么）

### 1. 教学案例：被嫌弃的“早读课”
*   **背景**：学校规定每天早上 7:00-7:30 是英语早读，班主任发现大家都在打瞌睡或者发呆，效果极差。
*   **❌ 伪需求/普通思维**：
    *   班主任觉得是大家**态度**不端正。
    *   **解决方案**：增加巡逻次数，谁睡觉就罚站。
    *   **结果**：学生站着也发呆，心里抱怨，厌恶英语。
*   **✅ 产品思维（用户视角）**：
    *   **用户调研**：找几个学生聊天。发现大家不是不想读，而是昨晚作业多睡得晚，早上太困张不开嘴；而且一直读课文很枯燥。
    *   **痛点分析**：生理性困倦 + 内容枯燥 = 无法专注。
    *   **产品改良（MVP方案）**：
        1.  **功能1（激活）**：前5分钟不读英语，放一首英文High歌，全班起立跟着节奏拍手（唤醒身体）。
        2.  **功能2（互动）**：把“朗读”改成“角色扮演PK”，同桌两人一组，一人演A一人演B，比谁读得更有感情（增加社交和竞争机制）。
    *   **价值**：学生清醒了，英语也练了。

### 2. 学生实战任务：拯救“收作业”灾难
**任务背景**：
作为课代表，每天早自习下课要把全班50人的数学作业收齐交到办公室，简直是一场噩梦。有的找不到本子，有的交错组，有的缺交，最后老师还要怪你没收齐。

**分组挑战（15分钟）**：
请利用产品思维，把“收作业”看作一个产品，重新设计这个流程。

**思考框架（填写下表）**：

| 步骤 | 思考引导 | 你们的方案 |
| :--- | :--- | :--- |
| **1. 用户是谁？** | 除了课代表（你自己），还有谁是用户？ | （提示：交作业的同学、批作业的老师） |
| **2. 用户痛点？** | 同学为什么交得慢？老师为什么会生气？ | （例如：同学不知道最后期限；本子摞在一起老师很难翻...） |
| **3. 核心功能？** | 怎么做能让同学交得快，且让你点数最快？ | **（请设计一个新规则或新工具）** |
| **4. 预期爽点** | 改革后，大家会获得什么好处？ | |

*   **参考答案方向**：
    *   *设计一个“快交箱”：按学号分5个格子，同学自己投递，谁没交一目了然（视觉化管理）。*
    *   *改变时间点：不要早自习下课收，改为晚自习放学收（错峰）。*

## 模块二：项目经理实战 —— 拆解目标，掌控资源
**核心口号**：大象装进冰箱分三步，登月计划也能拆成一张清单。

### 1. 教学案例：混乱的“班级大扫除”
*   **背景**：周五下午全校大扫除，要求1小时内彻底清洁教室（包括擦窗、拖地、擦黑板、清理图书角）。
*   **❌ 普通思维（一团乱麻）**：
    *   卫生委员喊：“大家快动起来！”
    *   **结果**：5个人抢一把扫帚；有人擦玻璃没报纸；有人在发呆不知道干嘛；最后时间到了，地还没拖干，被扣分。
*   **✅ 项目思维（结构化拆解）**：
    *   **项目目标**：16:00前完成清洁，并通过学校检查（验收标准：窗户无指纹，地面无水渍）。
    *   **资源盘点**：全班40人，扫帚4把，拖把2把，抹布10块。
    *   **WBS（任务拆解）**：
        *   **第一阶段（准备 5min）**：搬桌子组（力气大的男生）；物资组（去打水、分抹布）。
        *   **第二阶段（执行 40min）**：
            *   高空作业：擦窗组（个子高的，先擦窗，避免擦完地再踩脏）。
            *   地面作业：扫地组（先扫） -> 拖地组（后拖，从里往外退着拖）。
        *   **第三阶段（收尾 15min）**：验收组（卫生委员模拟检查，查漏补缺）。
    *   **风险控制**：如果拖把不够怎么办？-> 安排一部分人先擦桌子，错开工具使用时间。

### 2. 学生实战任务：策划“我的18岁成人礼旅行”
**任务背景**：
假设你们小组的成员都刚满18岁，你们计划在高考后的暑假，用 **5000元预算**（总共），去一个 **陌生的城市** 进行为期 **3天2夜** 的旅行。

**分组挑战（15分钟）**：
请利用项目思维，画出这次旅行的项目计划图。

**思考框架（填写下表）**：

| 项目要素 | 思考引导 | 你们的计划 |
| :--- | :--- | :--- |
| **1. SMART目标** | 具体要去哪？目的是什么（吃美食/看风景/纯放松）？ | （例如：去成都，目标是吃遍3家网红火锅，拍一部Vlog） |
| **2. 限制条件** | 钱、时间、安全 | **预算红线：5000元。时间：3天。** |
| **3. 任务拆解(WBS)** | 出发前、旅行中、回家后，分别要做什么？ | **请画出至少3个阶段，每个阶段3个关键动作。** |
| **4. 风险管理** | 可能会发生什么倒霉事？怎么预案？ | （例如：没买到票？有人生病了？钱花超了？） |

*   **参考答案方向**：
    *   *阶段一（行前）：订票（比价）、定攻略（谁负责找路）、收拾行李（清单）。*
    *   *阶段二（行中）：Day1打卡景点 -> Day2自由活动 -> Day3买特产返程。*
    *   *风险：为了防止钱花超，设立“记账员”角色，每天晚上复盘余额。*
